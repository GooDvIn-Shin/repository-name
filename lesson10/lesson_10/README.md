# Автоматизация тестирования с интеграцией Allure-отчетов (Урок 10)

Данный проект содержит кроссбраузерные автотесты для калькулятора и интернет-магазина, написанные с использованием паттерна **Page Object Model (POM)**. Код полностью задокументирован, строго типизирован и снабжен подробной разметкой шагов для генерации отчетов **Allure**.

---

## 🛠️ Особенности реализации проекта

1. **Калькулятор (`test_calc.py`)**: запускается в браузере **Google Chrome**. Тестирует арифметические операции с искусственной задержкой.
2. **Интернет-магазин (`test_shop.py`)**: настроен для работы в браузере **Mozilla Firefox**.
3. **Обход блокирующих окон**: в настройки драйверов добавлены флаги для отключения встроенных менеджеров паролей и всплывающих окон об «утечке данных», которые перекрывают элементы страниц.
4. **Стандарты кода**: код полностью соответствует **PEP 8**. Для длинных ссылок, перенос которых ломает логику Selenium, использован официальный маркер `# noqa: E501`.

---

## Предусловия и установка пакетов

Перед запуском убедитесь, что на компьютере установлены браузеры **Google Chrome** и **Mozilla Firefox**, а также утилита **Allure CLI** ([официальная инструкция по установке](https://allurereport.org)).

Для установки необходимых Python-библиотек (в случае проблем с глобальным PATH) используйте гарантированный запуск через модуль:

```bash
python -m pip install pytest selenium allure-pytest flake8 black
```

## Как запустить тесты для формирования отчета

Поскольку тесты распределены по разным браузерам, вы можете запускать их как по отдельности, так и вместе. Сырые результаты выполнения будут автоматически собираться в папку `allure-results`.

### Запустить только калькулятор (в Chrome):
```bash
python -m pytest test_calc.py --alluredir=allure-results
```

### Запустить только магазин (в Firefox):
```bash
python -m pytest test_shop.py --alluredir=allure-results
```

### Запустить ВСЕ тесты проекта одновременно (Комбо):
```bash
python -m pytest . --alluredir=allure-results
```

## 📊 Как просмотреть сформированный отчет Allure

После успешного завершения тестов, можно визуализировать результаты в виде красивого веб-интерфейса в браузере.

### Вариант 1: Запуск временного локального сервера (Рекомендуемый)
Команда создаст отчет во временной папке и автоматически откроет его в вашем браузере по умолчанию:
```bash
allure serve allure-results
```
*Для завершения работы сервера нажмите `Ctrl + C` в окне терминала.*

### Вариант 2: Статическая компиляция отчета
Если нужно скомпилировать постоянные HTML-файлы отчета в директорию `allure-report`:
```bash
allure generate allure-results -o allure-report --clean
```
Чтобы открыть уже сгенерированный отчет из папки:
```bash
allure open allure-report
```

## 🔍 Проверка стиля кода (Линтинг)

Для проверки соответствия кода стандартам PEP 8 используйте команду Flake8, исключая из проверки служебные папки и результаты отчетов:

```bash
python -m flake8 . --exclude=.pytest_cache,allure-results,allure-report,venv
```
